# lx Brainstorm：先发散，再收敛

## 前置条件

- 先读取 `docs/lx-workflow/CONTEXT.md` 和相关 ADR（如果存在）。
- 如果目标、边界或关键约束仍然模糊，停止发散，要求用户先完成 `/lx-grill`。

## 过程

1. 用一句话重述要解决的问题和不可违反的约束。
2. 提出至少三个真正不同的方向，而不是同一方案的换皮版本。
3. 对每个方向说明：核心机制、优点、代价、主要风险、适用条件和可验证方式。
4. 用用户已确认的术语比较方案，不引入未经解释的新名词。
5. 明确推荐一个方案，但保留用户选择权。
6. 记录已选方案和被拒绝方案的理由，供 `/lx-writing-plan` 使用。

本 Skill 只产生方案和决策记录，不写业务代码、不创建测试、不启动 Subagent。用户选定方向后，等待用户明确要求进入计划阶段。
