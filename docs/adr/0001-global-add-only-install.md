# ADR 0001: 全局 Skill 采用命名空间隔离与只新增安装

## 状态

已接受

## 背景

同事可能已经拥有 Cursor、Claude 或其他来源的同名 Skills。直接写入或覆盖全局目录会破坏个人配置，也会让分享流程不可预测。

## 决策

所有本项目 Skill 使用 `lx-` 前缀，并安装到 Cursor 用户级 `~/.cursor/skills/`。安装器先完成全量冲突预检：同名且内容不同则停止；同名且内容相同则跳过；只有不存在的目录才复制。

## 后果

安装安全且可重复，但上游 Skill 的更新需要通过本仓库发布新版本；用户必须自行解决真正的同名冲突。
